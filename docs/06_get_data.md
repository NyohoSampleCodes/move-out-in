# 06. データの入手

ここからは Python を離れて、「本物のデータをどこから、どうやって手に入れるか」を説明します。

## 使うデータ

日本では、市区町村をまたいで引っ越しをすると住民票を移す必要があります。総務省統計局は、その住民票の異動をもとに毎月・毎年、**「住民基本台帳人口移動報告」** という統計を公表しています。今回はこの中の、都道府県から都道府県への移動者数がわかる表を使います。

- 統計名: 住民基本台帳人口移動報告 年報（実数）
- 表番号: **2**
- 表題: 「男女、移動前の住所地別都道府県間移動者数」

この表には、「〇〇県から△△県へ何人移動したか」が、47 都道府県 × 47 都道府県の組み合わせすべてについて載っています。これはまさに vis_peopleflow が使っているのと同じ種類のデータです。

## データの入手元（e-Stat）

**e-Stat**（政府統計の総合窓口, https://www.e-stat.go.jp/ ）は、日本政府の統計データをまとめて公開している公式サイトです。個人のブログやまとめサイトではなく、統計局が直接公開している一次データなので、安心して使えます。

### ダウンロード手順

1. e-Stat（https://www.e-stat.go.jp/）にアクセスする。
2. 検索欄で「住民基本台帳人口移動報告」を検索する。
3. 「年報（実数）」の中から、見たい年（例: 2024年）を選ぶ。
4. 表の一覧から **表番号2「男女、移動前の住所地別都道府県間移動者数」** を探す。
5. ダウンロードのアイコンから **「EXCEL」**（「EXCEL 閲覧用」ではない方）を選んでダウンロードする。

「EXCEL 閲覧用」はレイアウトが人間の目で見やすいように整形されたファイルで、逆に Python での自動処理には向きません。今回使うのは、レイアウトが規則正しい方の「EXCEL」ファイルです。

## このプロジェクトにすでに入っているデータ

上の手順を毎回繰り返すのは大変なので、このプロジェクトには **2020年・2021年・2022年・2024年** の4年分を、あらかじめ `data/raw/` フォルダに用意してあります。

```
data/raw/idou_2020.xlsx
data/raw/idou_2021.xlsx
data/raw/idou_2022.xlsx
data/raw/idou_2024.xlsx
```

`idou`（移動）という名前に、対象の年をつけたファイル名にしています。07 以降では、まずこの `idou_2024.xlsx` を使って読み込み方を学びます。

## 発展: 自分でもっと年を増やしてみる

2023年など、ここに含まれていない年のデータも、上の手順で自分でダウンロードして `data/raw/idou_2023.xlsx` のように保存すれば、11 で学ぶ複数年の処理にそのまま追加できます。

## Excel の中身がどうなっているか

このファイルを Excel などで開くと、次のような構成になっています（07 で Python から実際に読みます）。

- 1〜4行目: 統計名や表題などの見出し
- 5〜7行目: 列の見出し（都道府県名など、複数行にまたがっている）
- 8行目以降: 実際のデータ。1行が1つの「移動前の住所地（＝転出元）」に対応する
- 9〜55行目が、ちょうど北海道から沖縄県までの47都道府県分にあたる
- 列の方向には、47都道府県分の「転入先」の数値が並んでいる
- 同じ都道府県から同じ都道府県への移動（例: 北海道→北海道のような県内移動）にあたるマスは `-`（ハイフン）になっている
