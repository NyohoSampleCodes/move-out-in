# 01. 環境の確認

## Python の実行環境

このプロジェクトでは、Python 本体やライブラリの管理に **uv** というツールを使います。uv は、

- どのバージョンの Python を使うか
- どんな外部ライブラリ（openpyxl や matplotlib など）が必要か

を `pyproject.toml` というファイルに記録しておく道具です。この教材では、学習内容をわかりやすくするため、サンプルコードは `python` で直接実行します。

## インストールされているか確認する

ターミナルで次のコマンドを実行してください。

```
uv --version
```

バージョン番号（例: `uv 0.11.29`）が表示されれば大丈夫です。何も表示されない・エラーになる場合は、[uv 公式サイト](https://docs.astral.sh/uv/getting-started/installation/)の手順に従ってインストールしてください。

## Python を動かしてみる

プロジェクトのフォルダ（`move-out-in`）の中で、次のコマンドを実行してみましょう。

```
python --version
```

`Python 3.12.x` のように表示されれば、Python の準備は完了です。必要なライブラリは、プロジェクトの案内に従って自分の環境に追加してください。

## コードの実行方法

これから `steps/` フォルダに、回ごとのコードを置いていきます。実行するときは、`python` の後ろにファイルのパスを続けてください。

```
python steps/02_variables.py
```

`openpyxl` や `matplotlib` などのライブラリが必要なステップでは、あらかじめ自分の Python 環境にライブラリをインストールしておいてください。ライブラリの追加には `uv add ライブラリ名` が使えます。
