# 13. まとめと次の一歩

お疲れさまでした。ここまでで、次のことができるようになりました。

- 変数・リスト・`for` 文・関数・ファイルの読み書き、という Python の基本
- 総務省統計局が公開している一次データを、正規の配布元（e-Stat）から入手する
- `openpyxl` で Excel ファイルを読み込み、必要な数値だけを取り出す
- 辞書と `json` を使って、自分たちの目的に合った形にデータを整形する
- `matplotlib` で静的なグラフを、`plotly` でインタラクティブな図を作る
- 三角関数とベジェ曲線で円環レイアウトを作り、`Dash` で hover に応じて図を描き直す
- 半透明の重なりで、動きに頼らずに流れの向きを表現する
- 複数年のデータをまとめて処理し、推移を追う

`data/raw/` の Excel という「生データ」から、`data/processed/` の JSON・PNG・HTML という「使える形」まで、自分の書いたコードだけで一直線につなげられました。これは vis_peopleflow が最終的な見た目を作るまでにやっていることと、本質的には同じ作業です。

## vis_peopleflow との違い

`11` で作った図は、都道府県を円周上に並べ、外周バーで転入超過・転出超過を、hover で転入・転出の流れを表示するという、vis_peopleflow とほぼ同じ体験を実現できました。違いとしては、

- vis_peopleflow は HTML + D3.js（ブラウザだけで完結）、このプロジェクトは Python + Dash（自分のパソコンでサーバーを立てる）。Dash はサーバーとブラウザを1往復させて図を作り直す都合上、D3.js のようなネイティブアニメーションほど滑らかには動かせません。点を動かすアニメーションも試しましたが、頻繁にサーバーへ問い合わせが発生してカクついてしまったため、`11` では動きに頼らず、半透明の弧を重ねることで向きを伝える方式に落ち着いています。
- vis_peopleflow はタップで固定できる・スマホ対応など、UI の作り込みがより丁寧

といった点が残っています。データの中身（`prefs`・`flows`・`in`・`out`・`net`）はほとんど同じ形にしてあるので、**データの取得・整形の部分はすでに完成していて、あとは見た目を磨き込むだけ** という状態です。

## 発展課題

どれから手をつけても構いません。気になったものから試してみてください。

1. **もっと年を増やす** — 06 の手順で、2010〜2019年や2023年、最新年のデータをダウンロードし、`data/raw/` に `idou_2019.xlsx` のように保存して `steps/12_multi_year.py` の `years` に追加してみましょう。長い期間の推移が見えるようになります。
2. **男女別に見る** — 07 で読んだ Excel には、実は「総数」列の隣に「男」「女」の列もありました（11列目が総数、12列目が男、13列目が女、というように）。これを使って、男女別の移動傾向の違いを調べてみましょう。
3. **21大都市のデータを使う** — 表2には、都道府県だけでなく「21大都市」（札幌市・仙台市など）の列・行も含まれています。都道府県単位より細かい移動の様子を見られます。
4. **地図の上に表示する** — `folium` や `plotly` の `choropleth` 機能を使うと、日本地図の上に都道府県ごとの色を塗って可視化できます。新しいライブラリなので `uv add folium` のように追加が必要です。
5. **11 の図をさらに磨く** — タップで表示を固定する（`clickData` を使う）、複数の都道府県を同時に選べるようにする、外周バーにも hover で数値を表示する、など vis_peopleflow に近づける余地はまだあります。
6. **本家の D3.js 版を読んでみる** — vis_peopleflow の[ソースコード](https://github.com/klareswasser/vis_peopleflow/)を読んでみましょう。`migration_data.json` の構造は、このプロジェクトの `data/processed/migration_2024.json` とよく似ているはずです。円環レイアウトやベジェ曲線など、`11` で Python で書いたのと同じ考え方が JavaScript（D3.js というライブラリ）でどう書かれているか、見比べてみると理解が深まります。
