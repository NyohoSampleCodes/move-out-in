# 00. このプロジェクトについて

## 目標

[vis_peopleflow](https://klareswasser.github.io/vis_peopleflow/) というウェブページは、日本の都道府県のあいだでどれくらいの人が引っ越しをしているかを、円環状のグラフで見せてくれます。外側の棒の高さで「転入超過（人が増えた）」か「転出超過（人が減った）」かがわかり、都道府県をクリックすると、そこに出入りする人の流れが線で表示されます。

このプロジェクトの目標は、**このページと同じ種類のデータを自分で取ってきて、自分の手で可視化してみること** です。まったく同じ見た目のものをいきなり作るのではなく、次のような手順を踏みます。

1. 総務省統計局が公開している「住民基本台帳人口移動報告」というデータを、正式な配布元（e-Stat）から入手する
2. Excel 形式で配布されているそのデータを、Python で読み込む
3. 都道府県ごとの「転入者数・転出者数・転入超過数」や、「どの県からどの県へ何人動いたか」を計算する
4. 扱いやすい JSON という形式に整えて保存する
5. まずは棒グラフのようなシンプルな図で確認し、次にインタラクティブな図に挑戦する

## 前提知識

**Python を書いたことがなくても大丈夫です。** 「変数」「リスト」「ファイルの読み書き」「関数」といった言葉を聞いたことがない前提でテキストを書いています。パソコンの操作（フォルダを開く、ターミナルでコマンドを打つ）に多少慣れていれば十分です。

## 進め方

`docs/` フォルダの中のファイルに `01`, `02`, `03`... と番号がついています。この番号の順番に読んでください。それぞれのテキストには、対応する実際に動かせるコードが `steps/` フォルダに用意されています。

読んで終わりにせず、実際に手元でコードを実行し、値を変えてみたり、`print()` を増やして中身を覗いてみたりしながら進めるのがおすすめです。

## 全体の流れ

```
[e-Stat: 総務省統計局のデータ]
        │  (06) ダウンロード（人の手で）
        ▼
   data/raw/*.xlsx          … 元データそのもの（Excel）
        │  (07) openpyxl で読み込む
        ▼
   Python のリスト・辞書
        │  (08) 集計して json で保存
        ▼
   data/processed/*.json    … 自分たちで作った、扱いやすいデータ
        │  (09)(10) 可視化する
        ▼
   グラフ・インタラクティブな図
        │  (11) 円環レイアウト + hover 連動（Dash）
        ▼
   vis_peopleflow に近い見た目の図
        │  (12) 複数年に拡張する
        ▼
   複数年をまとめたデータ・年ごとの推移グラフ
```
