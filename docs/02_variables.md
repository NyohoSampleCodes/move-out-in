# 02. 変数と print

## 今回学ぶこと

- 変数（値に名前をつけて覚えておく仕組み）
- `print()`（画面に文字や数字を表示する）
- 数値と文字列の違い

## 変数とは

プログラムの中で何かの値を覚えておきたいとき、「変数」という名前のついた箱に値を入れておきます。

```python
prefecture = "北海道"
population_change = -8637
```

`prefecture` という名前の箱に `"北海道"` という文字列を、`population_change` という箱に `-8637` という数値を入れています。`=` は「代入する（箱に入れる）」という意味で、数学の「等しい」とは違うので注意してください。

## print で中身を見る

箱の中身を確認したいときは `print()` を使います。

```python
prefecture = "北海道"
print(prefecture)
```

これを実行すると、画面に `北海道` と表示されます。文字列（文字の並び）は `"..."` か `'...'` で囲みます。数値は囲みません。

```python
population_change = -8637
print(population_change)
```

`print()` には複数の値を `,` で区切って渡すこともできます。

```python
print(prefecture, population_change)
# 北海道 -8637
```

## 数値の計算

数値を入れた変数は、そのまま計算に使えます。

```python
in_count = 53281   # 転入者数
out_count = 59566  # 転出者数
net = in_count - out_count
print(net)  # -6285
```

このように「転入者数から転出者数を引くと、転入超過数（マイナスなら転出超過）が求まる」という計算は、このプロジェクトで何度も出てきます。
